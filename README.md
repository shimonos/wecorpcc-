# WeCorpCC

WeCorpCC is a RuneLite plugin for the Corporeal Beast.

## Features

- Boosting Mode
- Solo Mode
- Mass Mode
- Player tracking
- Kill tracking
- Fang, Voidwaker, DWH and BGS tracking
- Rare drop tracking (Onyx, Arcane, Spectral, Elysian)
- Package management
- Session statistics
- Active/Inactive player tracking
