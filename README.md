# WeCorpCC

A RuneLite plugin designed to improve the Corporeal Beast experience with dedicated modes for Boosting, Solo, and Mass worlds.

## Features

### Boosting Mode
- Live player tracking
- Player kill counts
- Trip timer
- Kill timer
- Fang, Voidwaker, DWH, BGS and Elder Maul spec tracking
- Package tracking
- Customer management
- Player status indicators
- Low HP warnings
- Quick player actions

### Solo Mode
- Solo Corp preparation helper
- Spec tracking
- Ready notification
- Session timer
- Reset support

### Mass Mode
- Active member tracking
- Corp kill counter
- Trip timer
- Fang and Voidwaker spec counters
- Rare drop tracking:
  - Onyx
  - Arcane Sigil
  - Spectral Sigil
  - Elysian Sigil
- Session reset

## Plugin Modes

- Boosting
- Solo
- Mass

Switch between modes instantly from the plugin panel or RuneLite configuration.

## Requirements

- RuneLite
- Java 11+

## Installation

Available through the RuneLite Plugin Hub after approval.
